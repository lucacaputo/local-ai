## Description

Make the agent useful when nobody is watching it (doc-003 AF6, AN6, D2, D5): the web page, router and scheduler start with Windows while the model keeps unloading when idle; the game guard goes (decision-007 superseded, doc-003 section 5); each user schedules tasks in their own OpenClaw; results and confirmation requests reach company-domain users in Google Chat and everyone else as browser notifications from the web page.

Done when: B5 passes for a company-domain user and for a non-domain user, with the model unloaded when the task fires.

Out of scope: the office install; Google Chat for non-domain users.
